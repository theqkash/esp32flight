esp32flight

Standalone desk flight radar. No server, no subscriptions, no API keys.

Install from your browser v0.3.1

Connect the board over USB, click Install and pick the serial port. The full firmware (16 MB including airline logos, maps and the airport database) is written to the device. One binary fits all supported boards, the hardware is detected at boot.

Chrome or Edge on desktop required (Web Serial)

If no port shows up on Windows, install the WCH CH343 driver (Waveshare) or the CH340 driver (Guition) and try again. Flashing takes a few minutes.

Supported hardware

Waveshare ESP32-S3-Touch-LCD-7 7" 800x480, the original target
Waveshare ESP32-S3-Touch-LCD-4.3 4.3" sibling, same firmware (also 4.3B and 5)
Guition JC8048W550 5" 800x480 budget board, autodetected
Android 5.0+ the same radar as an app: download the APK

What you get

  • Live aircraft within 1 to 250 nm, airline logos, types, class filter (airliners, military, helicopters...)
  • Routes with cities, flags and local airport times, ETA, photos of the actual aircraft
  • Route map, radar on a real map, session stats and a retro CRT radar view with a rotating sweep
  • Optional rain radar overlay (RainViewer) on all maps and as the retro scope's weather echo
  • Map or retro-radar screensaver, flyover alerts, push notifications, MQTT/Home Assistant
  • Web panel with live map, history and OTA updates at http://esp32flight.local

First boot

Tap the gear icon, scan and pick your 2.4 GHz Wi-Fi network, type the password on the on-screen keyboard and save. The device locates itself, fetches nearby flights and starts tracking. Later updates install over the air from the web panel, the cable is only ever needed once.
